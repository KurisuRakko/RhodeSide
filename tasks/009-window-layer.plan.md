# 009 站在窗口上的小人：跟窗口同层、不在焦点不乱走、跳起来不卡

2026-10-01，接 `1090c11`（窗口撞到时跳上去）之后 Rakko 提的三件事。已定（含第二轮问答：飞行带子用在所有下落、扫描频率不变、失焦时可在露出来的那段里溜达）：
站在窗口上就**一直和这个窗口同层**；脚下被前面的窗口盖住就**留在下面**，正常步速走到露出来的地方；整个顶边都被盖住就**在下面坐着等**。

## 现状（为什么会这样）

- 小人窗口是 `.floating` 层，永远在所有窗口上面。站在后面窗口 A 上时，A 的顶边被前面窗口 B 挡住的那段
  在 `Platforms.compute` 里被减掉了：小人走到那里 = 走出平台 → 掉下去；点了 B 把 A 盖住 → 脚下平台没了 → 掉下去；
  掉之前那一瞬间小人画在 B 前面，看着像悬空。
- 跳起来卡：日志里弹跳后主线程连卡 497 + 510 ms（fall）。飞行中每帧 `setFrameOrigin` 挪小人窗口，每次都要等 WindowServer
  （以前测过的坑），你那时正拖着窗口，WindowServer 更忙。
- 已验证：`NSPanel.order(.above, relativeTo: 别的程序的窗口号)` 能把小人窗口插到那个窗口正上方、前一个窗口下面（Mac 上实测 2 ms）。

## 方案

### A. 平台：被挡住的顶边也留着，标成「被盖住」（PetCore）
- `Platform` 加 `covered: Bool`（默认 false）。`Platforms.compute` 把被前面窗口挡住的那几段也输出，`covered = true`。
- 被盖住的段：**只有本来就站在这个窗口上的小人能站、能走**。下落落点、并排走过去（别的窗口）、随机走的范围、
  跳窗边、`WindowHop.target`、叠叠乐都不认它。

### B. 焦点（PetCore + 原生）
- `World` 加 `focus`：未知 / 某个窗口 / 没有。原生层每次扫描算：最前面那个应用（`NSWorkspace.frontmostApplication`）
  在窗口列表里最靠前的那个窗口；它没有可站的普通窗口（Rhodeside 自己开着设置窗口、Raycast、菜单栏小工具、点了桌面）时取最前面的别人的窗口
  （反方提醒：当成「没有焦点」会让所有小人都被困住）。
- 站在**不在焦点**的窗口上（`Brain`）：
  - 只在**脚下这段露出来的顶边里**溜达：随机走的目标不出这段、不跳窗边，走到这段的头就停下（之后往回走），
    不走到并排的别的窗口上、不走进被盖住的地方；套组不拉它（`go` / 集合点都不理）；
  - 失焦前已经在走的，走到这段的头也就停下，不会掉下去；
  - 窗口回到焦点就恢复正常。
- 脚下那段被盖住（`covered`）、醒着、能走（有走路动画、非战斗形态、非「原地停留」）：正常步速走到**同一个窗口顶边上最近的露出来的那段**
  （身子整个露出来的位置），中间经过的被盖住的段照样能走；走到了停下，之后按上一条在那段里溜达。整个顶边都被盖住 → 原地坐着等，露出来了再走过去。

### C. 层级：站在窗口上就和窗口同层（原生）
- 每只小人算「该贴哪个窗口」：自己（叠着的看最下面那只）**站稳在窗口 A 上** → 贴 A；在地上、在空中、被拎着 → 照旧 `.floating`。
- 贴 A：`panel.level = .normal` + `order(.above, relativeTo: A)`；叠在头上的那几只同层、排在下面那只上面（沿用 `raiseStack`）。
  只在「该贴的窗口」变了时动一次（落到窗口上、走到并排的另一个窗口、跳起来、被拎起），平时不碰窗口层级。
- 层级被别人打乱（点了 A，A 升到最前把小人盖在下面；别的窗口插进来）：每次窗口扫描顺带拿到**含自己窗口**的前后顺序，
  小人不在「A 之上、A 前面那个别人的窗口之下」就重新排一次。应用切换（`didActivateApplication`）时马上扫一次，少闪一下；
  扫描频率不变（Rakko 选的：同一个应用里切窗口最多被盖 ~0.3 秒）。
- 被盖住的小人点不到、拖不动（鼠标落在前面的窗口上），这是同层的自然结果。

### D. 飞行时不再每帧挪窗口（原生 + 前端，协议 3 → 4）
- 进入下落（弹跳、被扔、走出窗口边、窗口关了掉下来都算）时，把小人窗口**一次**拉高成一条覆盖整段弹道的带子：
  下沿 = 所在屏幕的地面，上沿 = 弹道最高点 + 身高（`Brain` 给出 `apexY = 脚 + vy²/2g`）。飞行中窗口不动，
  原生层每帧在 `pos` 里多发脚在带子里的高度 `y`、竖直速度 `vy`、带子高度 `h`，网页按 `y` 画、在两次更新之间外推。
  脚出了带子（横着飞到另一块屏幕、意外更高）才重设一次；落地后缩回原来的矮带子。
- 网页报的包围盒带上画脚的高度 `fy`，原生层的鼠标命中框按它上下平移（空中也能接住）。
- 新 App 配旧前端会把小人画在带子底部 → 前端协议 `bridge` 3 → 4（`RemoteUpdater.bridge`、`publish.mjs` 的 `BRIDGE`），
  只发前端会被旧 App 拒收；这次要全量部署。
- 风险：起跳 / 落地各有一次窗口改大小 + 画布重建，可能有一帧空白；部署后在日志里加一次「挪窗口耗时 > 50ms」的警告来确认卡顿确实没了。

## 测试
- `PlatformsTests`：被挡住的段输出成 `covered`（原有用例改成只看露出来的段）。
- `BrainTests` / 新 `FocusTests`：不在焦点不走、不跳窗边、`go` 被拒、走着时失焦停下；被盖住时走到最近露出来的段、整个被盖住坐着等；
  下落 / 随机走 / 并排走不认别的窗口被盖住的段；焦点未知时一切照旧（老用例不变）。
- `WindowHopTests`：目标不选被盖住的段。
- 网页：`pnpm check`。Mac：`pnpm mac:test`，全量 `mac:deploy` 后看日志 + `debug/state`（每只小人的 `layer`、平台的 `covered`）。
