# 007 · 六星模型库 + 设置页用词整理（待确认）

## A. 模型来源（已在做）

- `macos/scripts/fetch-prts.mjs`：PRTS 干员一览 → 137 名六星 → torappu 的 meta.json → 全部时装 × 基建/正面/背面，
  下到 `models-private/<干员名>/`（和荒芜拉普兰德同一布局），顺带存 `skins.json`（时装 key → PRTS 时装名）。
- 只收 Spine 3.8；新干员上线后重跑脚本 + `deploy.sh models` 即可。和拉普兰德一样只走登录后的更新通道。

## B. 模型库（登录后挑模型）

- **登录后不再自动下载任何模型**（荒芜拉普兰德的 default 只作为「默认勾选」）。
- 引导页第 2 步 = 模型库：左边列表（搜索框 + 勾选框，显示干员名、时装数、大小），
  右边预览：**点哪个就只下那个干员默认时装的基建模型（约 0.1–0.5 MB），只循环播待机（Relax）一个动作**，
  不加载其他时装和战斗模型；右下「下载所选（N）」。
- 预览包在发布时单独打（`v1/previews/<id>-<version>.tar.gz`，同样要票据），App 下到缓存目录，用完可丢。
- 设置页「模型」区加「模型库…」按钮打开同一个窗口（不在引导里也能挑）。
- 设置页：模型区加搜索、在线模型默认折叠；桌宠的「模型」下拉也列出未下载的在线模型，选中即自动下载。

## D. 战斗形态（正面 / 背面）的控制面板

- 形态不是基建时：桌宠不走动（只能拖动、下落），控制面板的「活动」换成「动作」下拉框，列出这套模型的全部动画，
  选中的循环播放（记在配置里，下次启动还是它）。
- 套组按钮：按动画名自动认出成套的动作（`Skill_Begin → Skill_Loop → Skill_End`、`Attack_Begin/…/End`、
  `Start → Idle` 等），每组一个按钮，点一下按顺序播一遍（Loop 段播约 3 秒），播完回到下拉框选中的动作。

## E. 服务器每天自动拉新六星

- rakkoserver 上一个 systemd 用户定时器，每天 04:30 跑 `fetch-prts.mjs`（只下新增 / 变化的文件），
  有变化就 `deploy.sh models` 重新签名发布目录；App 端只会在模型库里看到新干员，不会自动下载。
- 每次的结果写日志（新增了谁、跳过了谁），失败不影响已发布的目录。
