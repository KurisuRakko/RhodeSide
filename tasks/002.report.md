## 6. console 错误与那条 404 的定位

- 正式第 2 遍三页：**console error 0、warn 0、pageerror 0、requestfailed 0**，页面级 4xx/5xx 响应 **0**；`rhodeside` 消息每页都是 `ready` + `loaded`。
- **第 1 遍 page 1 出现过 1 条** `Failed to load resource: the server responded with a status of 404 (Not Found)`（requestfailed 为空，说明是 404 响应而非网络失败）。为定位它我做了三步：
  1. 直接 `curl`：`/favicon.ico` → **404**（`web/` 下没有 favicon，pet.html 也没有 `<link rel="icon">`）；`/pet.html`、`/src/pet/main.ts`、`/lib/spine/spine-webgl.js` 全部 200。
  2. 用**全新空 profile** 跑 Chrome，`--log-net-log=…` 抓底层 netlog：请求清单里出现且仅出现一个 8066 上的可疑 URL —— `http://127.0.0.1:8066/favicon.ico`；同时 console 复现了同一条 404。
  3. netlog 里所有 `models/...` 请求都是 200 且是页面真需要的那些，没有任何模型资源 404。

→ **结论：那条 404 是浏览器自动请求 `/favicon.ico`，与 pet.html/模型载入无关。** 第 2 遍及之后多次复跑没再出现，是因为同一 profile 已缓存了这个负结果。
给 Claude 的建议（非必须、非 bug）：在 `web/public/` 放一个 `favicon.ico`，或在 `pet.html` 加 `<link rel="icon" href="data:,">`，可消掉这条噪音。

> 诊断期间我曾用一条**手写错百分号编码**（`%E8%8A%9C` 解成「茜」）的 URL 复现，页面按 `?? list[0]` 静默回退载入了 `test-puppet`；用 `quote()` 正确编码后载入 char_1038_whitw2 正常。**这是我的测试笔误，不是 pet.html 的 bug**（见 §8 备注 2）。

## 7. 判据说明

1. **画布 alpha 连通域**（主判据，同 001）：alpha≥40 为前景，0.5 倍缩放后 8 邻域连通域。完整渲染在这批模型上恰好 1 个连通域；破损（MAX_TEXTURE_SIZE=64）会散成 22~33 块。阈值：`n_comp==1`→完整；`≤4 且 largest≥0.9`→基本完整；`≥8 或 largest<0.5`→碎。
2. **严格 RGBA 逐通道比对**：新旧截图同尺寸直接按字节比，报最大/平均通道差、差>2 数、alpha IoU。判「无差异」的门槛设成 `chan_max_diff=0`（本轮实际达到的最严标准）。
3. **透明背景**：四角 + 最外 3px 环 alpha 全 0；前景只 1 个连通域（⇒ 除人形外没有非透明像素）；最大透明连通域触到四边且占比 >0.92。
4. **脚底位置**：`最低非透明像素行` vs `画布高 − layout.footY`，报实测差（−1.05 / −1.63 / −1.07 px）。
5. **翻转**：镜像前后 IoU 对比 + 质心镜像预测误差 + 左右边缘列最大 alpha。
6. **运行时分支取证**：`createImageBitmap` 包装记录 `hadResize/in/out`，证明 resize / canvas 兜底 / 降级分支各自被走到。

## 8. 观察 / 备注（都不是本次要改的 bug）

1. **页 3 的 `layout.h=1188` > 调试视口 600**：`layout` 是给原生透明窗口算的（`union` 覆盖全部动画的并集，正面含大幅挥武器动作，所以很高）。调试模式固定用浏览器视口，当前帧 bbox 最低/最高行是 223~465，没被裁；但换到把武器甩到更高的动画帧，600 高的画布顶部就可能截掉。这是**调试视口的取景下限**，不是渲染错误——原生层按 `layout.w/h` 设窗口就不会有这个问题。
2. **模型名不匹配时静默回退 `list[0]`**（`main.ts` 的 `?? list[0]`）：`?model=` 打错字不会报错，而是默默画出 `test-puppet`。这是既有设计（本次改动前就有），只是调试时容易误导。要不要在找不到时 `post({type:'error'})` 请 Claude 定夺。
3. **favicon 404**：见 §6，纯噪音。
4. `001-verify.py` 有一处 Pillow 弃用告警（`Image.getdata`），不影响结果。
